# CommunityPay

A privacy-first mobile money concept, built as a React prototype.

## About

CommunityPay explores what a mobile money experience could look like if privacy came first — designed with everyday users in mind, particularly in markets where mobile money is central to daily financial life.

This is a personal side project, built to experiment with the idea and sharpen my React skills outside of my day-to-day work.
